GPS sources

    Order is saved straight away.

    Tried from top to bottom: the first active GPS is used and the next one takes over when it stops. 254 is the Orca Core's own GPS. A GPS whose position has not changed for 60 s uses its own GNSS fix while that still changes; if that has not changed either it counts as frozen and is skipped. Exception: the Orca Core (254) keeps its fix while the boat lies still and moves it on after about 10 m; it stays usable (shown as hold), but a live GPS is preferred over it.
